### Andros island web map

2019 MSc cartography project, rebuilt 2026 · Python, GeoPandas, rasterio, Leaflet, OpenStreetMap

An interactive map of Andros, built in one HTML file from the original 1:50,000 ΕΓΣΑ87 data and a 13 m DTM. It has relief shading, searchable villages, beaches, churches and monuments, and click-anywhere elevation with WGS84 and Greek Grid coordinates. You can draw a route to get its elevation profile. Optional OpenStreetMap layers add health and public services, springs and waymarked trails. It's designed so a small island municipality can host it without a map server.
